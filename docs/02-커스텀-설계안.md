# 커스텀 설계안

## 3~4인 확장 방식
| 원작 2인 | 확장 |
|---|---|
| 양면 돌(빨강/흰색) | 좌석별 색 돌 4종(진홍·백은·청람·비취). 돌은 **공용 공급**에서 꺼냄 — 다 쓰면 판 종료 |
| 영웅 = 상대 돌 뒤집기 | 영웅(기사) = **아무 상대**의 돌을 내 색으로 바꿈. 팀전이면 같은 팀 돌은 대상 아님 |
| 2인 모두 못 움직이면 종료 | **인원 수만큼 연속 패스**하면 종료 |
| 24장 / 손패 5 | 인원이 늘면 카드가 부족 → "카드 벌 수"(같은 세트 2~3벌) + 검증: 카드 ≥ 인원 × (손패 + 2) |
| 9×9 / 돌 52 | 3~4인 권장 11×11 / 돌 84~92 (원작의 "빈 칸 대비 돌 ≈ 65%" 비율 유지, 로비에서 자동 추천) |
| 동점: 영웅 덜 쓴 쪽 | 그대로 (팀전은 팀 합산) |

4인 팀전: 좌석 1·3 vs 2·4, 같은 팀 돌은 **한 영역으로 이어져 계산**되어 협력 플레이가 생긴다.

## 설정 항목
| 항목 | 범위 | 원작 |
|---|---|---|
| 보드 크기 | 5~13 | 9 |
| 공용 돌 | 8~168 (빈 칸 이하) | 52 |
| 막힌 칸 | 0~16 (180° 대칭 무작위, 칸 수의 1/5 이하) | 0 |
| 이동 거리 | 1~4 (보드보다 작게) | 1~3 |
| 대각선 카드 | on/off (off면 4방향) | on |
| 카드 벌 수 | 1~3 | 1 |
| 손패 상한 | 3~8 | 5 |
| 기사 카드 | 0~8 | 4 |
| 손패 공개 | on/off | on |
| 영역 점수 | 칸 수² / 칸 수 | 칸 수² |
| 대각선 영역 연결 | on/off | off |
| 판 수 | 1~5 (선 플레이어 순환, 점수 합산) | 1 |
| 턴 제한시간 | 0~300초 (초과 시 자동: 돌 놓기 > 카드 가져오기 > 기사 > 패스) | 없음 |
| 팀전 | 4인만 | — |

## 방/운영 (기존 Expedition Lines와 동일한 틀)
- 방 코드 4자리 + QR/링크, 방 암호(scrypt 해시, 방 단위 5분 10회 제한), 관전, 재접속 토큰, 방장 승계/강퇴/순서 변경
- 방 최대 5개, 모두 나간 뒤 1시간 유휴면 해제, 방장 방 닫기, 매치 후 각자 로비 복귀(대기 로비)
- 끊긴 플레이어 차례는 20초 뒤 다른 플레이어가 "대신 진행"
- 감정 표현(허용 목록, 1초 1회·10초 5회)
