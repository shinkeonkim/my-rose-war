# 원작 규칙 조사 — 장미전쟁 (Rosenkönig / The Rose King)

출처: 나무위키 "장미전쟁(보드게임)", 보드엠 상품 페이지, 그리고 널리 알려진 원작 규칙. 나무위키는 사용자 작성 문서라
세부(카드 장수 등)는 공식 룰북과 대조가 필요하다. 아래 "확인 필요"는 두 페이지에 명시되지 않아 일반적으로 알려진 규칙으로 채운 항목.

## 기본 정보
- 디자이너 Dirk Henn, 1992, KOSMOS. 2인, 약 30분. 국내판은 다이브다이스 수입판 "장미전쟁".
- 동명의 "장미전쟁: 랭카스터 대 요크"(지만게임즈)와는 다른 게임.

## 구성
| 구성물 | 내용 |
|---|---|
| 보드 | 9×9 격자 |
| 돌 | 52개, 양면(한쪽 붉은 장미 = 랭카스터, 다른 쪽 흰 장미 = 요크). 공용 |
| 왕관 | 1개, 두 플레이어가 함께 움직임. 시작은 보드 정중앙 |
| 이동(파워) 카드 | 검이 가리키는 방향 + 거리 숫자. 8방향 × 거리 1·2·3 = 24장 (확인 필요) |
| 영웅(기사) 카드 | 플레이어당 4장, 가문 색으로 구분 |

## 준비
- 왕관을 가운데에 놓고, 각자 영웅 4장 + 이동 카드 5장. 남은 이동 카드는 더미.
- **손패는 모두 공개** — 상대가 무엇을 할 수 있는지 보이는 것이 핵심 긴장감.

## 차례 (셋 중 하나)
1. **이동 카드 내기**: 왕관을 카드 방향·거리만큼 옮기고, 도착한 **빈 칸**에 내 색 돌을 놓는다.
2. **카드 가져오기**: 손패가 5장 미만이면 더미에서 1장.
3. **영웅 + 이동 카드**: 왕관을 **상대 돌이 있는 칸**으로 옮기고 그 돌을 뒤집어 내 색으로. 영웅 카드는 한 번 쓰면 끝.
- 보드 밖·내 돌이 있는 칸으로는 이동 불가. 중간 칸은 상관없음(점프).
- 할 수 있는 게 없으면 패스. 더미가 바닥나면 버린 카드를 섞어 새 더미 (확인 필요).

## 종료와 점수
- 돌 52개를 모두 쓰거나, 두 사람 모두 움직일 수 없으면 종료.
- **상하좌우로 이어진 같은 색 영역마다 (칸 수)²**. 대각선은 연결 아님. 합이 큰 쪽 승리.
- 동점 변형: 영웅을 덜 쓴 쪽 승리(나무위키 언급).

## 이 프로젝트에서의 해석
- 카드 방향은 **보드 기준 절대 방향**(위 = 북)으로 통일. 원작은 각자 앞에 카드를 두는 물리적 배치 때문에 방향 해석이 문서마다 다르게
  설명되는데, 온라인에서는 모두가 같은 화면 방향을 보므로 절대 방향이 혼동이 없다.
- 이름("Crown March"), 가문(진홍·백은·청람·비취), 문장(꽃잎·초승달·별·잎사귀), 카드·보드 그림은 모두 자체 제작.
